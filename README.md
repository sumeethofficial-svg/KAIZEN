## 🖤 What is KAIZEN?

**KAIZEN (改善)** means **continuous improvement**.

KAIZEN is a growing collection of practical browser-based tools for working with:

- 📄 PDF files
- 📝 Documents
- 🖼️ Images
- 📦 Archives
- 🛠️ Everyday file utilities

The idea is simple:

> Common file operations shouldn't require a complicated application or a different website for every task.

KAIZEN brings these workflows together into one consistent interface.

---

## ✨ Why KAIZEN?

KAIZEN is built around three principles:

| | Principle | What it means |
|---|---|---|
| ◆ | **Private** | Process files locally whenever the workflow allows it. |
| ↯ | **Fast** | Keep tools focused and lightweight. |
| ✓ | **Simple** | No unnecessary setup or complicated workflows. |

The project focuses on making small file operations feel like part of one polished product rather than a collection of disconnected utilities.
